# NeonVisuals — Fabric 1.21.0

Клиентский мод визуалов и HUD для **Minecraft Java 1.21.0 + Fabric**.

## Скачать готовый мод через GitHub

После загрузки этого проекта в GitHub готовый JAR будет собираться на серверах GitHub Actions с Java 21 и автоматически публиковаться в разделе **Releases**. Java и Gradle на своём компьютере для скачивания устанавливать не нужно.

1. Создай на GitHub новый репозиторий с названием `NeonVisuals`. Для публичного скачивания другими людьми выбери **Public**.
2. Не ставь галочки создания README, `.gitignore` и License — эти файлы уже есть в проекте.
3. Распакуй ZIP проекта на компьютере. На странице нового репозитория нажми **Add file → Upload files** и загрузи **содержимое** распакованной папки, включая папку `.github`.
4. Нажми **Commit changes**. На вкладке **Actions** появится сборка `Build and publish NeonVisuals`.
5. Когда workflow завершится успешно, открой вкладку **Releases**. В последнем релизе `NeonVisuals build ...` скачай `neonvisuals-1.0.0.jar` в разделе **Assets**.

При каждом новом коммите в `main`/`master` GitHub автоматически соберёт новую версию и обновит последнюю Release. Для ручной пересборки открой **Actions → Build and publish NeonVisuals → Run workflow** (выбирай ветку `main`).

Постоянная ссылка на самый свежий JAR имеет вид:

`https://github.com/ТВОЙ-АККАУНТ/NeonVisuals/releases/latest/download/neonvisuals-1.0.0.jar`

Замени `ТВОЙ-АККАУНТ` на имя своего GitHub-аккаунта.

## Установка в Minecraft

1. Установи Fabric Loader для **Minecraft Java 1.21.0**.
2. Установи **Fabric API 0.102.0+1.21**.
3. Скопируй `neonvisuals-1.0.0.jar` в папку `.minecraft/mods`.
4. Запусти профиль Fabric 1.21.0. В игре нажми **Right Shift**, чтобы открыть меню.

## Функции

### Render / эффекты
- Custom Crosshair — настраиваемые длина, отступ, толщина, прозрачность и центральная точка.
- Hit Marker — короткий визуальный маркер при клике по существу под прицелом.
- Hit Particles — частицы при melee-атаке по существу; настраиваются количество, разброс и скорость.
- Sword Adjust — настройка смещения X/Y/Z, масштаба и поворота меча в первой руке.
- Custom Fog — настройка расстояния, формы и цвета клиентского тумана.
- White Enchant — настройка осветления цвета зачарованного глинта до белого.
- Jump Circle — кольцо частиц при прыжке.
- Player Trail — лёгкий след частиц во время прыжка.
- Damage Pulse — экранный импульс при получении урона.

### HUD
- FPS, координаты XYZ, Ping и CPS.
- Keystrokes (WASD + Space).
- Totem Counter.
- Armor HUD с прочностью брони.

### Меню и настройки
- Открытие на **Right Shift**.
- Вкладки Render / HUD / Style.
- ЛКМ по модулю — включение/выключение.
- ПКМ по модулю — быстрые настройки.
- Настройки автоматически сохраняются в `config/neonvisuals.json`.
- Дополнительные параметры доступны через Render → выбери модуль → QUICK SETTINGS.

## Локальная сборка (необязательно)

Если всё же хочешь собрать мод на своём ПК, нужны Windows 10/11 x64, интернет и **Java JDK 21**. Запусти `build.bat`; после сборки JAR появится в `build/libs`. Для обычного скачивания через GitHub выполнять локальную сборку не требуется.

## Требования мода

- Minecraft Java 1.21.0
- Fabric Loader 0.15.11 или новее, совместимый с 1.21.0
- Fabric API 0.102.0+1.21
- Java 21 для запуска Minecraft

Мод клиентский: серверу его устанавливать не нужно. Проверяй правила конкретного сервера в отношении HUD и визуальных модификаций.
